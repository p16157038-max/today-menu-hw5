# 今天吃什麼？

依自己的預算與口味，從自訂菜單挑選一餐的互動網頁。HW5 Vibe Coding 作業作品。新版採用奶油、蜜桃、薄荷與淡紫色，配上笑臉麵碗與餐點小圖示。

[開啟互動網站](https://p16157038-max.github.io/today-menu-hw5/)

## 使用
直接開啟 `index.html`，或使用本 repository 的 GitHub Pages 網站。HTML、CSS、JavaScript 都在單一檔案，沒有額外安裝步驟或外部 API。

1. 設定預算、餐點類型與辣度，必要時勾選素食或只抽最愛。
2. 可先用「百元內搞定」「清爽素食」「今天想吃辣」重設條件，再點「幫我選一餐」。
3. 收藏喜歡的餐點；在表單新增菜單，或修改、刪除已有項目。

## 規格
- 餐點欄位：名稱（1–40 字）、預估價格（新臺幣 0–3000 元整數）、類型、辣度、素食標記。
- 預算留白不限，價格等於上限仍符合；所有條件取交集。
- 從符合清單等機率隨機選一個，連續抽選可重複。沒有符合項目時清除不合條件的結果並停用抽選。
- 新增、修改、刪除及最近一次刪除復原；同名項目會提示，不重複新增。
- 最愛可加入／取消，也可成為抽選篩選條件。
- 可勾選「不要連續抽到同一道」。有其他候選時排除上一道再等機率抽選；只剩一道仍可抽選。
- 保留最近五次抽選的名稱與當時價格。這是抽選紀錄，不代表實際吃過。清除紀錄保留菜單與最愛，也忘記上一道。
- 菜單與最愛以 localStorage 保存，資料限於相同瀏覽器、網站來源與頁面路徑；不傳到伺服器。儲存失敗時提示，本次仍可操作。
- 抽選紀錄也保存在本機；篩選條件與不重複開關不保存。新版仍能讀取先前的菜單與最愛。
- 響應式排版、欄位標籤、可見鍵盤焦點與抽選讀屏提示。

起始菜單有 28 份餐點及 12 種分類，保留原始八份，新增 20 份台灣常見餐點與聚餐選擇。示範預算為每人 45–2700 元；品牌與聚餐金額是預算估計，可自行修改，不是即時店家報價。素食與辣度是手動標記，點餐前應確認實際內容。網站不提供營養建議、付款或訂餐。

## AI 協作與實際修改
主題由使用者在 AI 提出的三個方向中選定。AI 協助整理規格、撰寫程式、檢查與修正。

第一版測試發現預算輸入單獨的負號時被當成空白不限，修正為先檢查 `validity.badInput`，無效值提示並停用抽選。程式審查另發現復原刪除可能繞過同名限制，加入衝突檢查。收藏與刪除後也調整鍵盤焦點，並將頁面路徑加入儲存鍵，避免同網域其他路徑的作品共用菜單。

本機瀏覽器已實際檢查新增、修改、刪除／復原、同名衝突、預算邊界與多條件篩選、無符合結果、最愛、重新整理保存及 390px 手機版操作。這是功能測試，沒有宣稱訪談、真實店家資料或使用者成效研究。

新版已檢查 1280、390、320px 無水平溢出；連續七次抽選在不重複模式沒有連續同名，紀錄最多五筆且重整後保留；單一候選仍可抽選；修改價格或刪除餐點不會改寫舊的抽選快照。這些是實際功能檢查，沒有驗證對 Gen Z 的吸引力。
