## 使用

1. 首頁按主要入口開始選餐，設定每人預算。照片分類可直接選類型；搜尋、價位、辣度等在進階偏好展開。每個啟用條件可個別移除。
2. 有候選時按「幫我選一餐」看符合理由；也可在卡片「加入比較」，最多三道。
3. 沒有候選時看「換一個條件，找回選擇」。每個選項明示只改哪一項、可得到幾道，點選後才套用，不直接抽選或取消素食。
4. 比較保留已選餐點，更新超出預算及不符條件；可個別移除或清空。
5. 收藏常吃餐點；由菜單管理入口展開新增、修改、刪除及復原。手機可使用固定操作列抽選與查看比較。

預算為上限，3000元包含便宜餐點；看高價餐可搭配價位區間。排序不改抽選機率，抽選使用全部符合餐點。

## 完整功能

起始40餐12類，麥當勞與KFC各4餐，7餐達千元、4餐達兩千元。保留品牌別名搜尋、多條件交集、價格排序、12張分批顯示、最愛、5筆歷史快照、避連續重複與菜單管理。

估價45至2900元可自行修改，非即時店家報價。素食與辣度為手動標記，點餐前向店家確認。比較只依菜單欄位，不作營養或營運成效判斷。

本輪新增單條件恢復、當前符合理由及三餐比較。第四個比較會拒絕並保留前三項；編輯或刪除會更新事實。不影響抽選與舊資料。

雙擊index.html或用靜態HTTP伺服器開啟；不需安裝、金鑰、模型或網路字型。Node邏輯檢查：
