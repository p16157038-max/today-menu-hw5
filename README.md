# 今天吃什麼？

依自己的預算與口味，從自訂菜單挑選一餐的互動網頁。HW5 Vibe Coding 作業作品。新版採用奶油、蜜桃、薄荷與淡紫色，配上笑臉麵碗與餐點小圖示。

[開啟互動網站](https://p16157038-max.github.io/today-menu-hw5/)

## 使用
直接開啟 `index.html`，或使用本 repository 的 GitHub Pages 網站。HTML、CSS、JavaScript 都在單一檔案，沒有額外安裝步驟或外部 API。

1. 設定每人預算、價位區間、餐點類型與辣度，必要時勾選素食或只抽最愛。
2. 可先用「百元內搞定」「清爽素食」「今天想吃辣」重設條件，再點「幫我選一餐」。
3. 想看高價選擇時，用高價餐快捷入口，或選擇 1000–1999 / 2000–3000 元區間。也可將卡片依價格由低至高或由高至低排列。
4. 收藏喜歡的餐點；在表單新增菜單，或修改、刪除已有項目。

## 規格
- 餐點欄位：名稱（1–40 字）、預估價格（新臺幣 0–3000 元整數）、類型、辣度、素食標記。
- 預算留白不限，價格等於上限仍符合；預算、價位區間、搜尋與其他條件取交集。
- 價位區間分為 1000 元以下、1000–1999 元、2000–3000 元，另有不限選項。3000 元預算上限仍包含便宜餐點；要看高價餐可搭配區間。
- 預設交錯顯示日常、中高價和高價餐，也可選價格遞增或遞減。排序只影響顯示次序，不改抽選機率。
- 從符合清單等機率隨機選一個，連續抽選可重複。沒有符合項目時清除不合條件的結果並停用抽選。
- 新增、修改、刪除及最近一次刪除復原；同名項目會提示，不重複新增。
- 最愛可加入／取消，也可成為抽選篩選條件。
- 可勾選「不要連續抽到同一道」。有其他候選時排除上一道再等機率抽選；只剩一道仍可抽選。
- 保留最近五次抽選的名稱與當時價格。這是抽選紀錄，不代表實際吃過。清除紀錄保留菜單與最愛，也忘記上一道。
- 菜單與最愛以 localStorage 保存，資料限於相同瀏覽器、網站來源與頁面路徑；不傳到伺服器。儲存失敗時提示，本次仍可操作。
- 抽選紀錄也保存在本機；篩選條件與不重複開關不保存。新版仍能讀取先前的菜單與最愛。
- 響應式排版、欄位標籤、可見鍵盤焦點與抽選讀屏提示。

起始菜單有 34 份餐點及 12 種分類，保留原始八份，先新增 20 份台灣常見餐點與聚餐選擇，再補入 6 份高價餐。示範預算為每人 45–2900 元，其中 7 份達 1000 元、4 份達 2000 元。品牌與聚餐金額是預算估計，可自行修改，不是即時店家報價。素食與辣度是手動標記，點餐前應確認實際內容。網站不提供營養建議、付款或訂餐。

新增高價餐為田季發爺極品海陸燒肉 1100 元、山里烤物午間套餐 1500 元、晶華栢麗廳平日午餐 1900 元、山里精進會席 2200 元、晶華栢麗廳假日午晚餐 2300 元、山里澳洲和牛網燒會席 2900 元；保留原有和牛燒肉 2700 元。新增六份的每人金額參考[田季官方菜單](https://www.tianji.com.tw/menu/)、[山里官方菜單](https://www.okurataipei.com.tw/download/118/)及[晶華栢麗廳價格表](https://www.regenttaiwan.com/dining/brasserie/braorder2014_tw.pdf)，考量 10% 服務費後向上取整；實際價格仍依餐期、門市與店家確認。

## AI 協作與實際修改
主題由使用者在 AI 提出的三個方向中選定。AI 協助整理規格、撰寫程式、檢查與修正。

第一版測試發現預算輸入單獨的負號時被當成空白不限，修正為先檢查 `validity.badInput`，無效值提示並停用抽選。程式審查另發現復原刪除可能繞過同名限制，加入衝突檢查。收藏與刪除後也調整鍵盤焦點，並將頁面路徑加入儲存鍵，避免同網域其他路徑的作品共用菜單。

本機瀏覽器已實際檢查新增、修改、刪除／復原、同名衝突、預算邊界與多條件篩選、無符合結果、最愛、重新整理保存及 390px 手機版操作。這是功能測試，沒有宣稱訪談、真實店家資料或使用者成效研究。

## 第六輪擴充

加入餐點與品牌搜尋，搜尋會和預算、類型、辣度、素食、最愛條件一起套用。每人最高預算可快速選擇 100、300、800、1500、3000 元或不限；上限仍包含更便宜的餐點。0–3000 是輸入範圍，0 可供自訂免費餐點。

## 第七輪高價餐與比較功能

補入 6 份 1100–2900 元的餐點，提供三個價位區間、價格排序及高價餐快捷入口。兩個高價餐入口重設篩選，設定 3000 元上限與各自的 1000–1999 或 2000–3000 元區間，並移至餐點卡片；預設順序也將不同價位交錯顯示，使高價餐在首批卡片中就能看到。

菜單版本升為 3，依保存版本分階段更新：原始版本可補入 26 份，已升級至版本 2 則只補入 6 份。每階段只執行一次，同名餐點不重複加入，使用者的修改、最愛與紀錄保留；上一輪已刪除的餐點也不會被再次補回。
